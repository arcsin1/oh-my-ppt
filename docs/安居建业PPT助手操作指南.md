# 安居建业 PPT 助手操作指南（内部测试版）

## 1. 适用范围

本工具供安居建业内部员工制作可继续编辑的 PPTX 文件。生成内容会遵循公司内置模板：封面、可选目录、正文页和固定末页；正文默认使用楷体。

使用 AI 生成功能前，员工需自行准备个人模型 API Key。Key 仅用于本人调用模型，不能发到工作群、邮件或 PPT 中。

## 2. 首次使用：连接个人 AI 服务

1. 打开软件左侧的“设置”。
2. 在“连接个人 AI 服务”中选择 **DeepSeek API**。
3. 保持默认的 API Base URL；如公司后续统一提供地址，再按管理员通知修改。
4. 填写可用的模型 ID 和个人 API Key。
5. 点击“验证并保存”。显示“已连接”后即可使用 AI 生成。

说明：

- API Key 不会写入 PPT、安装包或操作日志。
- 如果系统安全存储不可用，软件会拒绝保存 Key；请按提示检查系统登录状态后重试。测试版在 macOS 开发环境重启后可能需要重新填写 Key。
- 未配置 Key 时，仍可查看、编辑和导出已有 PPT；仅 AI 生成功能不可用。

## 3. 新建一份 PPT

1. 回到首页，点击“新建演示文稿”或输入制作主题。
2. 写清楚用途、受众、需要表达的事实和期望页数。例如：“面向项目例会，汇报本周已确认进度与下周计划，6 页，不要虚构日期、部门或验收结论。”
3. 如有已确认的 Word、表格或材料，按页面提示上传或粘贴要点。
4. 点击“开始生成”，等待生成完成。

生成逻辑：

- 第 1 页：公司封面模板；
- 第 2 页：仅在确有目录需要时使用目录模板；
- 中间页面：统一使用公司正文模板；
- 最后一页：保留公司原末页，不修改文字和版式。

## 4. 查看与编辑

1. 在生成结果中逐页检查标题、正文、图片和页码。
2. 发现不准确的内容，直接在软件中编辑，或重新生成对应页面。
3. 对日期、部门名称、数据、验收结论等事实信息必须人工核对；没有来源时不要把模型生成的内容当作已确认事实。
4. 生成过程背景会显示公司 Logo 的放大动画，这是界面提示，不会写入导出的 PPT。

## 5. 导出并用 WPS 打开

1. 在演示文稿页面点击“导出 PPTX”。
2. 选择保存位置，得到 `.pptx` 文件。
3. 用 WPS 演示或 Microsoft PowerPoint 打开文件。
4. 随机检查：封面、正文页、末页、页码、字体和可编辑性。
5. 确认无误后，再通过公司既有渠道发送或归档。

导出的文件是标准 PPTX：文本、图片和版式可以继续编辑。动画以导出结果和 WPS/PowerPoint 的实际兼容性为准。

## 6. 常见提示

| 现象 | 处理方式 |
| --- | --- |
| “未连接”或无法生成 | 到“设置”填写并验证个人 API Key。 |
| API Key 验证失败 | 检查是否误填了网页会员账号、中文字符、空格、引号或 `Bearer` 前缀；请重新粘贴开发者 API Key。 |
| “系统安全存储不可用” | 检查是否已正常登录当前系统账户；关闭软件后重新打开再尝试。 |
| 模型写了不确定的日期、部门或结论 | 删除或改为已确认信息；不能靠模型补全事实。 |
| WPS 中排版异常 | 先确认软件已升级到最新版；保留原 PPTX 和截图，并反馈给产品维护人员。 |

## 7. 内部测试建议

每次测试建议至少检查一次完整流程：连接 AI → 输入已确认素材 → 生成 → 人工编辑核对 → 导出 PPTX → 用 WPS 打开并确认可编辑。

反馈问题时请附上：操作步骤、页面截图、生成主题和导出文件（如内容不涉密）。不要提供 API Key。
